## Decisions

- Software status: **PASS** (D020 budget discipline holds; no leakage — inner
  inputs disjoint from outer test donors by test; candidate fits bitwise
  identical A-ON vs A-OFF).
- Scientific adoption: **DROP** — no worthwhile benefit (no fold reaches the
  gain margin) with unacceptable harm (recovery/usage margins exceeded in 3 of
  4 folds). Default remains OFF. Scope: min-loss donor-blocked selection at
  DEVELOPMENT simulation; biological tier untouched (no claim there either way).

## Context that does not rescue the result

The feasibility NO-GO (D035) means "benchmark unresolving" is a live
alternative for the *null* folds — but the harm folds are not nulls: A
actively selected a worse rank where the baseline selected K_true (base
outer_0). A one-standard-error parsimony variant (brief §P1) is a legitimate
*named* follow-up and is deliberately **not built here**: adding it now would
be enlarging the feature to obtain a favorable result.

## Supported / unsupported scope

Supported: on resolvable-to-flat DEVELOPMENT curves, pure-min-loss inner
validation overselects to the grid boundary and degrades recovery; the
silhouette baseline (largest-among-stable, δ=0.04812) selected K_true in 2/2
base folds. Unsupported: any claim about real data, about the unbuilt 1-SE
variant, or about ranks outside the tested grids.
